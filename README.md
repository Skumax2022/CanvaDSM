# Canvas + DSM — System Designer

Инструмент системного проектирования: бесконечная доска (Canvas) + глобальная матрица зависимостей (DSM).

## Быстрый старт

### Вариант 1 — без сервера (рекомендуется для сдачи)

Откройте в браузере файл **`index.html`**.

> Работает через `file://`, не требует установки Node.js.

### Вариант 2 — Next.js

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- **Canvas** — пространства, прямоугольники, квадраты; вложенность; drag & drop
- **DSM** — матрица зависимостей с цветовой кодировкой типов
- **Stealth UI** — чёрно-белая тема, нижняя панель инструментов
- **Import / Export** — JSON-проекты

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `R` | Прямоугольник |
| `E` | Space (пространство) |
| `F` | Square (квадрат) |
| `Z` / `Ctrl+Z` | Отмена |
| `Space` | Дублировать |
| `Del` | Удалить |
| `Ctrl+C` / `Ctrl+V` | Копировать / вставить |
| `+` / `-` / `0` | Zoom |
| `Shift + drag` | Множественное выделение |

## Типы прямоугольников

| Тип | Цвет |
|-----|------|
| Базовый | Серый (stealth plate) |
| Функция | Фиолетовый |
| Число | Зелёный |
| Объект | Оранжевый |

Смена типа — кнопка с иконкой на элементе (или на plate-прямоугольнике без вложений).

## Структура проекта

```
index.html          — автономная версия (HTML + JS)
app.js              — логика canvas и DSM
hotkeys.config.js   — конфигурация горячих клавиш
app/                — Next.js версия
components/         — React-компоненты
lib/                — store, типы, утилиты
```

## Сборка

```bash
npm run build
npm start
```
